# Social Media – Edition Resonanz

Öffentliche Ablage für Videos und Bilder, die über Planungsdienste (Buffer, Metricool) auf TikTok, Instagram und Facebook veröffentlicht werden.

Bücher: „Wer zuerst aufsteht“ / „The First to Stand Up“ / „Le Premier à se lever“ von Bernd Blasius.

## TikTok-Slideshows @editionresonanz (seit 14.11.2026)

- `werkzeug/slides.py` – Bauprogramm: macht aus `tiktok/en/JJJJ-MM-TT.json` die Bilder `tiktok/en/JJJJ-MM-TT/01.jpg …` (1080 × 1920) und den Freigabebogen `uebersicht.jpg`.
- `vorrat/` – Bildvorrat mit Liste `vorrat.json` (Motiv, Zeit 1914/heute, Schlagworte, Einsätze).
- `tiktok/en/` – je Beitrag eine Textdatei und ein Ordner mit den fertigen Slides. Weitere Sprachen später als eigener Ordner.
- Arbeitsgrundlage: Doc „Edition Resonanz – TikTok-Fahrplan“.
